# Security

Please do not report vulnerabilities in public issues or pull requests.
Use GitHub's [private vulnerability reporting](https://github.com/lmilojevicc/readmd/security/advisories/new)
for this repository (Security → Report a vulnerability).

Include the affected version or commit, OS and terminal, reproduction steps,
and impact. Use a minimal example without credentials, private documents, or
unnecessary personal data. Do not open a public issue if private reporting is
unavailable; wait until private reporting is enabled.
